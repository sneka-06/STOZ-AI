My journey of learning HTML and CSS

Learning Web Development

My journey into web development started with learning HTML. HTML, which stands for HyperText Markup Language, is used to create the basic structure of a webpage. It helped me understand how different elements such as headings, paragraphs, links, lists, tables and sections are arranged on a website.

At first, creating a webpage with HTML felt quite simple. I learned how to create headings using h1, h2 and h3 tags and how to write paragraphs using the p tag. I also learned how links work using the a tag and how different pages can be connected together.

I started learning basic CSS properties such as colors, backgrounds, fonts, margins and padding. I also learned how to add borders, rounded corners and shadows to elements. These small changes made a big difference to the appearance of my website.

One of the things I enjoyed learning was the hover effect. By using the hover selector, I can make buttons, links and blog sections change when the mouse moves over them. This makes the website feel more interactive.

What I Learned

  • How HTML structures a webpage
  • How to create links between different pages
  • How to use headings, paragraphs and lists
  • How CSS changes the appearance of HTML
  • How to use margin and padding
  • How to create simple hover effects

My Next Step

I want to continue practicing HTML and CSS by building more small websites. After becoming comfortable with the basics, I plan to learn JavaScript so that I can make my websites more interactive and dynamic.

Understanding the basics of CSS

Learning CSS

CSS stands for Cascading Style Sheets. It is used to style and design websites. While HTML is used to create the structure of a webpage, CSS is used to make that webpage look beautiful.

With CSS, we can change the color, size, spacing, font and position of different elements on a webpage. We can also create buttons, cards, navigation bars and many other designs.

One of the things I learned while working with CSS is that small changes can make a big difference. Changing padding, margins, colors and borders can completely change how a website looks.

CSS Concepts I Learned

  • Colors and backgrounds
  • Margins and padding
  • Borders and border radius
  • Fonts and text styling
  • Hover effects

My Next Goal

My next goal is to learn Flexbox and responsive design so that I can create websites that work well on different screen sizes.
